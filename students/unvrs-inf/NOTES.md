Git - это система контроля версий, программа которая позволяет удобно контролировать коммиты (этапы) во время разработки ПО, не терять коммиты и безопасно возращаться к нужному снимку кодовой базы в прошлом в случае необходимости.

Репозиторий - это место хранения файлов и кода проекта вместе со всей истории их изменения. Хранится локально и на удаленном сервере.

Commit - это точка сохранения состояния кодовой базы на определенном этапе разработки, позволяет видеть кто, когда и какие именно изменения внес в код, создается локально и отправляется на удаленный сервер.

Branch - это независимая копия кодовой базы проекта, которая позволяет работать над новыми задачами не трогая основной код. Изначально всегда существует одна основная ветка (main) от которой можно создавать другие независимые ветки - от каждой такой независимой ветки можно создать другие ветки и эти ветки можно сливать друг с другом перенося изменения созданные из одной ветки в другую.

Конфликты слияния - это ситуация, когда git не может автоматически объеденить две ветки, потому что в них были сделаны изменения которые противоречат друг другу, например два человека могли изменить одну и ту же строчку в одном файле, либо же один человек изменил файл, а другой в это же время его удалил. Git позволяет решить этот конфликт, решить какое изменение правильное и выбрать его, либо же объединить оба изменения и далее git завершит слияние.

Git flow

main - в парадигме git flow это постоянно живущая production ветка, в которой содержится только стабильная релизная версия проекта использующаяся в production. Вливать изменения в эту ветку можно только из веток hotfix/* и release/*. Прямой push в эту ветку запрещен.

develop - это еще одна постоянно живущая ветка, в которой содержится новый разрабатываемый код до следующего релиза стабильной версии проекта. Ветка порождается от ветки main и имеет все историю и изменения, которые уже есть в ветке main. Вливать изменения в эту ветку можно только из веток hotfix/*, release/* и feature/*. Прямой push в эту ветку запрещен.

feature/* - временная ветка в которой разрабатывается новый отдельный функционал для проекта, порождается от ветки develop и имеет все изменения и историю которая уже есть в ветке develop. Каждый раз создается от ветки develop разработчиком для реализации нового функционала программы. Ветка живет до того момента, пока новый функционал не будет полностью закончен, отлажен и одобрен через pull request для слияния в ветку develop, после слияния в develop, ветка feature удаляется.

release/* - временная ветка в которой происходят все необходимые подготовки для выпуска нового релиза в production для вливания в стабильную production ветку main и ветку develop после завершения работы с ней. Создается ветка от develop и содержит изменения и историю сделанные в develop. Живет ветка до момента вливания в main и develop, после удаляется.

hotfix/* - временная ветка в которой исправляют критический баг найденный в стабильной production версии приложения который нужно срочно закрыть. Создается ветка от ветки main и живет до момента вливания в ветку main и develop для устранения бага также в этой ветке и предотвращения бага в будуших релизах. Также при необходимости если баг затрагивает часть кодовой базы которая используется в ветке release, то помимо слияния в main и develop, слияние идет и в ветку release. После успешного слияния фикса в необходимые ветки, ветка hotfix удаляется.
